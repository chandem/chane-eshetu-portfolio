# Chane Eshetu — Personal Website

A responsive personal website built with React, TypeScript and Vite, introducing Chane's work across civil engineering, software, AI, and construction technology.

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Deploy to Vercel
Import this GitHub repository in Vercel. Framework preset: **Vite**. Build command: `npm run build`. Output directory: `dist`. No environment variables are required.

## Personalize before publishing
- Confirm the public contact email in `src/App.tsx`.
- Add a profile photo as `public/profile.jpg` and update the image block in `src/App.tsx` if desired.
- Confirm project demo URLs and descriptions before making the site public.
